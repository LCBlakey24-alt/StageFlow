# Custom activities and seven-day scheduling

Stage Flow's Admin session wizard supports Monday through Sunday.

The built-in **Custom activity** option is intended for clubs or services that do not fit the
predefined swimming / PE / gymnastics programmes.

- Admin supplies the activity name (for example Basketball Club or Rebound Therapy).
- If no Custom criteria group exists, Stage Flow automatically defaults the new activity to
  timetable/register mode with assessment switched off.
- Notes can still be enabled.
- Admin can later create Custom criteria groups in Settings and enable assessment on the session.
- Custom activities therefore do not need assessment criteria simply to exist on the timetable.
